## About me
{: .fs-7 .fw-300 style="margin-top: -1rem;" }

I'm a Senior Technical Writer with 15+ years of combined experience across software engineering and technical writing, including developer infrastructure, docs-as-code platforms, CI/CD publishing pipelines, and recently, AI-assisted documentation ecosystems.
{: .fs-5 .fw-300 }

## What I do
{: .fs-7 .fw-300 }

* I design and build documentation systems, from Docs-as-Code publishing pipelines (GitHub Pages, MkDocs, Jekyll, CI/CD automation) to canonical configuration standards that eliminate manual, one-on-one onboarding.
  {: .fs-5 .fw-300 }

* I write across the full technical spectrum: API documentation (OpenAPI/Swagger, REST, GraphQL, SOAP), developer playbooks, security and compliance documentation, runbooks, and architecture guides.
  {: .fs-5 .fw-300 }

* I've authored developer integration guides for Model Context Protocol (MCP) services in AI IDEs, enabling secure, compliant workflows for AI-assisted engineering.
  {: .fs-5 .fw-300 }

* I bring a former software engineer's eye to every doc. I've migrated services between languages and frameworks (C++ to Java, Node.js to Java Spring Boot), engineered REST APIs and authentication systems, and understand the systems I document from the inside.
  {: .fs-5 .fw-300 }

## Impact
{: .fs-7 .fw-300 }

* Documentation efforts contributed to a 94% completion rate across 39 platform epics in a recent role.
  {: .fs-5 .fw-300 }

* Docs-as-Code workflows, which I built, saved developers 90% of the time they previously spent hunting for information.
  {: .fs-5 .fw-300 }

* I've authored 79+ Confluence pages (touching 110+ total) used across engineering, product, and DevOps teams.
